Setup guide

Claude API 키 발급 가이드

처음이어도 10분이면 끝나요. 아래 순서대로만 따라 하세요.
키는 내 브라우저에만 저장되고, 비용도 내가 쓴 만큼만 나가요.

💳 시작 전에 꼭 알아두세요
· 키 발급은 무료지만, 크레딧을 먼저 충전해야 작동해요. (최소 $5, 약 7~8천 원)
· 댓글 1회 생성 비용은 약 $0.003(약 4~5원) — $5로 대략 1,000개 이상 생성할 수 있어요. (글 길이에 따라 달라요)
· Claude Pro 구독과는 별개예요. Pro를 쓰고 있어도 API 크레딧은 따로 충전해야 해요.
1
Anthropic 콘솔 가입
console.anthropic.com 에 접속해 구글 계정이나 이메일로 가입하세요. 이메일로 가입했다면 받은 편지함의 인증 링크를 눌러야 다음 단계로 넘어가요.
2
결제 카드 등록 + 크레딧 충전
콘솔 메뉴의 Billing(결제)로 들어가 카드를 등록하고 Buy credits로 $5를 충전하세요. 해외결제가 되는 카드(VISA·Master 등)가 필요해요.
⚠ 충전하지 않으면 키를 넣어도 "크레딧 부족" 오류가 나요. 가장 많이 막히는 단계예요.
💡 자동 충전(Auto-reload)은 꺼두면 예상치 못한 결제를 막을 수 있어요.
3
API 키 만들기
메뉴의 API Keys로 이동해 Create Key를 누르고, 이름(예: 블로그댓글)을 입력해 만드세요. sk-ant- 로 시작하는 긴 문자열이 나오면 그게 키예요.
⚠ 키는 만들 때 딱 한 번만 보여줘요. 바로 복사(Copy)해 두세요. 놓쳤다면 새로 만들면 돼요.
4
확장프로그램에 키 입력
크롬 우측 상단 퍼즐 아이콘 → 블로그 댓글 도우미 클릭 → ⚙ 설정에서 복사한 키를 붙여넣고 저장하세요. 이제 이웃 블로그 글에서 아이콘만 누르면 댓글이 생성돼요.

자주 묻는 질문

키를 넣었는데 오류가 나요

대부분 ① 크레딧 미충전, ② 키 앞뒤에 공백이 같이 복사됨, ③ 키 일부만 복사됨 중 하나예요. 콘솔의 Billing에서 잔액을 확인하고, 키를 다시 복사해 붙여넣어 보세요.

Claude Pro를 구독 중인데 그걸로는 안 되나요?

안 돼요. Pro(claude.ai) 구독과 API 크레딧은 결제가 따로예요. 확장프로그램은 API 키로만 작동해요.

요금이 갑자기 많이 나올 수 있나요?

충전한 크레딧 안에서만 쓰이고, 다 쓰면 멈춰요. 자동 충전을 켜지 않았다면 추가 결제는 생기지 않아요.

내 키가 개발자에게 전달되나요?

아니요. 키는 내 크롬 브라우저에만 저장되고, 댓글을 만들 때 Anthropic API로만 직접 전송돼요. 개발자 서버는 거치지 않아요.

키가 유출된 것 같아요

콘솔의 API Keys에서 해당 키를 삭제(Delete)하고 새로 만들어 확장프로그램에 다시 입력하세요.
