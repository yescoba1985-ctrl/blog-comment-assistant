0시작 전에: 비용 구조

확장프로그램 설치는 무료입니다. 댓글을 만들 때 드는 AI 이용료는 본인의 Claude API 계정에서 차감됩니다.

항목내용
확장프로그램무료
API 키 발급무료
크레딧 충전사용 전 선불 충전 필요 (최소 $5)

본문은 앞부분 최대 3,000자까지만 읽습니다
claude.ai 구독(Pro·Max 등)과 API 크레딧은 별개입니다.
claude.ai(채팅 서비스)에서 결제한 구독료나 추가 사용량은 이 확장프로그램에 쓰이지 않습니다. 반드시 아래 2단계의 Claude Console(platform.claude.com)에서 크레딧을 충전해야 합니다.

충전한 크레딧을 다 쓰면 요청이 멈출 뿐, 자동 충전(Auto-reload)을 켜지 않았다면 추가 결제는 발생하지 않습니다.

1Claude Console 가입

API 크레딧과 키는 Claude Console에서 관리합니다. (예전 주소 console.anthropic.com은 이 주소로 연결됩니다.)

Claude Console 열기https://platform.claude.com
  1. 위 주소에 접속해 구글 계정 또는 이메일로 가입·로그인합니다.
  2. 이메일로 가입했다면 받은편지함의 인증 메일 링크를 눌러 로그인을 마칩니다.
  3. 처음 접속 시 조직(Organization) 이름 등을 묻는 화면이 나오면 개인 이름 등으로 입력하고 진행합니다.

2크레딧 충전 (결제)

가장 많이 막히는 단계입니다. 충전하지 않으면 키를 넣어도 "크레딧 잔액 부족" 오류가 납니다.

결제(Billing) 페이지 바로가기https://platform.claude.com/settings/billing
  1. 위 결제 페이지로 이동합니다. (메뉴로 찾을 때: 좌측 Settings → Billing)
  2. Buy credits 버튼을 누릅니다.
  3. 충전 금액을 입력합니다. 처음에는 최소 금액인 $5를 권장합니다.
  4. 카드 정보와 청구지 주소(Billing address)를 입력합니다. 해외 결제가 가능한 카드(VISA, Mastercard 등)가 필요합니다. 국내 전용 카드는 결제되지 않을 수 있습니다.
  5. 결제 요약에서 크레딧 금액과 세금, 총 결제 금액을 확인하고 구매 버튼을 누릅니다.
  6. 결제 후 같은 Billing 페이지에서 Credit balance(잔액)가 $0보다 크게 표시되는지 확인합니다. 반영까지 몇 분 걸릴 수 있습니다.
자동 충전(Auto-reload)은 기본적으로 꺼둔 상태를 권장합니다. 켜두면 잔액이 기준 이하로 내려갈 때 자동으로 추가 결제됩니다.
계정(조직)이 여러 개라면 크레딧을 충전한 조직과 API 키를 만드는 조직이 같아야 합니다. 화면 좌측 상단의 조직 이름을 확인하세요.

3API 키 만들기

API 키 페이지 바로가기https://platform.claude.com/settings/keys
  1. 위 API 키 페이지로 이동합니다. (메뉴로 찾을 때: 좌측 Settings → API keys)
  2. Create key를 누릅니다.
  3. 키 이름(예: 블로그댓글)을 입력합니다. 만료 기간을 묻는다면 원하는 기간을 선택합니다. 기간이 지나면 새 키를 만들어 다시 입력해야 합니다.
  4. sk-ant-로 시작하는 긴 문자열이 나타나면 Copy를 눌러 복사합니다.
키 전체 내용은 만들 때 한 번만 보여줍니다. 복사하지 못했다면 해당 키를 삭제하고 새로 만들면 됩니다. 키는 비밀번호처럼 다른 사람에게 공유하지 마세요.

4확장프로그램 설치·고정

  1. 크롬 웹스토어의 블로그 댓글 도우미 페이지에서 Chrome에 추가 → 확장 프로그램 추가를 누릅니다.
  2. 크롬 주소창 오른쪽의 퍼즐 모양 아이콘(확장 프로그램)을 누릅니다.
  3. 목록에서 블로그 댓글 도우미 옆의 핀(📌)을 눌러 툴바에 고정합니다. 이제 주소창 옆에 아이콘이 항상 보입니다.

5키 입력·키 테스트

  1. 툴바의 블로그 댓글 도우미 아이콘을 눌러 팝업을 엽니다.
  2. 팝업 오른쪽 위 ⚙ 설정을 누릅니다.
  3. Claude API 키 칸에 3단계에서 복사한 키를 붙여넣습니다. (앞뒤 공백은 자동으로 제거됩니다.)
  4. 🔑 키 테스트를 누릅니다. ✓ 키 정상 · 크레딧 확인 완료 (저장됨)이 나오면 설정이 끝난 것입니다. 오류 문구가 나오면 8번 항목을 확인하세요.
  5. (선택) 내 블로그 주제(예: 육아일기, 맛집탐방)와 내 닉네임을 입력하면 댓글 작성 시 참고 정보로 함께 전달됩니다.
  6. 💾 저장을 누릅니다.

6단축키 설정 (선택)

아이콘을 클릭하는 대신 키보드로 팝업을 열 수 있습니다. 크롬 기본 기능입니다.

  1. 크롬 주소창에 chrome://extensions/shortcuts를 직접 입력하고 Enter를 누릅니다. (보안상 웹페이지의 링크로는 열리지 않아 직접 입력해야 합니다.)
    또는 chrome://extensions → 왼쪽 메뉴 단축키
  2. 목록에서 블로그 댓글 도우미를 찾습니다.
  3. 확장 프로그램 활성화 항목 옆의 연필 아이콘 또는 입력칸을 누릅니다.
  4. 원하는 키 조합을 누릅니다. 예: Windows Alt + Shift + B, Mac ⌥ Option + ⇧ Shift + B
    (Ctrl 또는 Alt(Mac은 ⌘ 또는 ⌥)가 포함된 조합이어야 하며, 다른 프로그램과 겹치지 않는 조합을 고르세요.)
  5. 자동 저장됩니다. 블로그 글 화면에서 설정한 키를 누르면 팝업이 열리고 바로 댓글 생성이 시작됩니다.
단축키가 동작하지 않으면 같은 페이지에서 다른 조합으로 바꿔 보세요. 다른 확장프로그램이나 운영체제 단축키와 겹치면 동작하지 않습니다.

7사용법

지원하는 사이트

네이버 블로그(blog.naver.com) · 티스토리(*.tistory.com) · 브런치(brunch.co.kr) · 벨로그(velog.io)

댓글 만들기

  1. 댓글을 달고 싶은 블로그 글 페이지를 엽니다. (블로그 메인·목록 화면이 아니라 개별 글 화면이어야 합니다.)
  2. 툴바 아이콘을 누르거나 6단계에서 설정한 단축키를 누릅니다.
  3. 팝업이 열리면 자동으로 글 읽는 중 → 댓글 생성 중 순서로 진행됩니다. 따로 누를 버튼은 없습니다.
  4. ✓ 생성 완료 · 클립보드에 자동 복사됨이 표시되면 댓글이 이미 복사된 상태입니다.
  5. 블로그의 댓글 입력창을 클릭하고 Ctrl + V (Mac: ⌘ + V)로 붙여넣습니다.
  6. 내용을 읽어보고 필요하면 고친 뒤 직접 등록합니다.

마음에 들지 않을 때

  • 팝업의 ↺ 다시 생성을 누르면 새 댓글을 만듭니다. 생성할 때마다 이용료가 차감됩니다.
  • "글 내용을 읽지 못했습니다"가 나오면 페이지를 새로고침(F5, Mac ⌘ + R)한 뒤 다시 시도하세요. 설치 직후에 이미 열려 있던 탭은 새로고침해야 동작합니다.
AI가 만든 문장은 글 내용을 잘못 이해할 수 있습니다. 등록 전에 꼭 확인해 주세요. 같은 문장을 여러 곳에 반복해서 다는 등 블로그 운영 정책에 어긋나는 사용은 피해 주세요.

팝업이나 키 테스트에서 나오는 문구에 따라 아래를 확인하세요.

표시되는 문구원인과 해결
크레딧 잔액이 부족해요 API 계정 잔액이 $0입니다.
① platform.claude.com/settings/billing에서 잔액을 확인하세요.
② claude.ai에서 결제했다면 API에는 적용되지 않습니다. Console에서 따로 충전해야 합니다.
③ 충전한 조직과 키를 만든 조직이 같은지 확인하세요.
④ 방금 충전했다면 몇 분 뒤 다시 키 테스트를 눌러 보세요.
API 키가 올바르지 않아요키가 잘못 복사됐거나 삭제·만료된 키입니다. API 키 페이지에서 새 키를 만들어 다시 붙여넣으세요.
이 API 키로는 요청할 권한이 없어요키 권한이나 조직 설정 문제입니다. 새 키를 만들어 입력하세요. 회사·팀 조직이라면 관리자 설정을 확인해야 할 수 있습니다.
요청이 너무 많아요짧은 시간에 요청이 몰렸습니다. 1분 정도 뒤 다시 시도하세요.
AI 서버가 잠시 혼잡해요일시적인 서버 문제입니다. 잠시 후 ↺ 다시 생성을 누르세요.
키 형식이 아니에요sk-ant-로 시작하는 API 키가 아닙니다. claude.ai 비밀번호나 다른 서비스의 키가 아닌지 확인하세요.
블로그 페이지가 아닙니다지원 사이트(7단계 참고)의 글 페이지에서 실행하세요.
인터넷 연결을 확인해 주세요네트워크 연결이나 회사 방화벽·VPN 설정을 확인하세요.

9자주 묻는 질문

claude.ai Pro를 구독 중인데 그걸로 쓸 수 없나요?
쓸 수 없습니다. claude.ai 구독과 API 크레딧은 결제가 따로입니다. 확장프로그램은 API 키와 API 크레딧으로만 동작합니다.

참고: Max·Team 플랜 구독자는 매월 제공되는 API 크레딧을 받을 수 있는데, Claude Console 조직을 플랜에 연결해야 Console의 Billing 페이지(Promotional credits)에 표시됩니다. 연결 방법은 Anthropic 공식 안내를 참고하세요.
요금이 예상보다 많이 나올 수 있나요?
충전한 크레딧 안에서만 사용되고, 잔액이 0이 되면 요청이 멈춥니다. 자동 충전(Auto-reload)을 켜지 않았다면 추가 결제는 없습니다. 사용량은 Console의 Settings → Usage / Cost에서 확인할 수 있습니다.
내 API 키가 개발자에게 전달되나요?
아니요. 키와 설정은 내 크롬 브라우저 저장소에만 저장되고, 댓글 생성 요청은 개발자 서버를 거치지 않고 Anthropic API(api.anthropic.com)로 직접 전송됩니다. 이때 열려 있는 글의 제목과 본문 일부가 함께 전송됩니다.
키가 유출된 것 같아요
API 키 페이지에서 해당 키를 삭제(Delete)하고 새 키를 만들어 확장프로그램에 다시 입력하세요.
댓글이 자동으로 등록되나요?
아니요. 댓글 문장을 만들어 클립보드에 복사하는 기능까지만 있습니다. 붙여넣기와 등록은 직접 해야 합니다.
다른 컴퓨터에서도 쓰려면?
각 컴퓨터의 크롬에 확장프로그램을 설치하고 같은 API 키를 다시 입력하면 됩니다. 키는 브라우저마다 따로 저장됩니다.
