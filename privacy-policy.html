개인정보처리방침

최종 업데이트: 2025년 5월

1. 수집하는 정보

블로그 댓글 도우미는 다음 정보를 처리합니다:

  • 현재 방문 중인 블로그 페이지의 텍스트 내용 (댓글 생성 목적으로만 사용, 저장 안 함)
  • 사용자가 직접 입력한 Claude API 키 (브라우저 로컬 스토리지에만 저장)
  • 사용자가 직접 입력한 블로그 주제 및 닉네임 (브라우저 로컬 스토리지에만 저장)

2. 수집하지 않는 정보

  • 개인 식별 정보(이름, 이메일 등)를 수집하지 않습니다
  • 외부 서버로 사용자 데이터를 전송하지 않습니다
  • 쿠키 및 트래킹을 사용하지 않습니다
  • 사용 기록 및 히스토리를 저장하지 않습니다

3. 제3자 서비스

댓글 생성을 위해 Anthropic Claude API를 사용합니다. 블로그 글 내용이 API 요청에 포함될 수 있으며, Anthropic의 개인정보처리방침이 적용됩니다.

4. 데이터 보안

API 키를 포함한 모든 설정 정보는 사용자의 브라우저 로컬 스토리지에만 저장되며, 외부로 전송되지 않습니다.

5. 변경사항

본 개인정보처리방침은 필요에 따라 업데이트될 수 있습니다. 변경 시 이 페이지에 반영됩니다.
